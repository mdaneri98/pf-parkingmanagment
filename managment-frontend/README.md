# MVP Parking Management - Frontend Web

## Instalación y Ejecución

### Prerrequisitos
- Node.js 18+
- npm

### Pasos
1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Ejecutar en desarrollo**:
   ```bash
   npm run dev
   ```

3. **Compilar para producción**:
   ```bash
   npm run build
   ```
